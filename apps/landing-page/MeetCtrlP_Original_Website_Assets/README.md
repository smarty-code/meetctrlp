# MeetCtrlP Original Website Asset Pack

These are newly generated, original watercolor-style illustrations for the MeetCtrlP marketing website. They take broad inspiration from the reference site's soft painted atmosphere, editorial whitespace, and warm natural palette, without reusing its artwork.

## Files

- **meetctrlp-hero-workflow.png**: Hero visual: customer phone, document flow, shop desktop and printer.
- **meetctrlp-printer-workspace-wide.png**: Wide shop desktop and printer scene for the product differentiator section.
- **meetctrlp-printer-workspace.png**: Alternative printer workflow illustration for a feature section.
- **meetctrlp-document-privacy.png**: Privacy and careful document handling visual. Avoid implying specific security controls not yet implemented.
- **meetctrlp-user-qr-upload.png**: Print User QR entry and upload visual. QR pattern is decorative and must not be used as a real shop QR code.

## Usage guidance
- Use as supporting editorial imagery, not as a substitute for accurate product screenshots.
- The desktop and printer interfaces are illustrative. Replace with real MeetCtrlP screenshots when available.
- The QR code in the upload illustration is decorative and is not a functional shop QR code.
- Do not claim specific privacy/security guarantees based solely on the privacy illustration.
- Keep asset paths in a central manifest/configuration layer.
- Use responsive image sizing, lazy loading below the fold, descriptive alt text, and aspect-ratio placeholders.
- These assets are visual components only; do not embed headings or CTA copy into the image.
