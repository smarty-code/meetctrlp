# Print user web app

This is a Next.js template with shadcn/ui.

## Adding components

To add a shared component, run the following command from the repository root:

```bash
pnpm --filter @ctrlp/ui exec shadcn add button
```

This will place the component in `packages/ui/src/components`.

## Using components

To use the components in your app, import them as follows:

```tsx
import { Button } from "@ctrlp/ui/button";
```
